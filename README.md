# NeuroQuest

An autonomous AI agent for game-based longitudinal neurological monitoring.

## Project Status

Day 1 — Agent Specification

## Core Technologies

- Amazon Bedrock
- Amazon Bedrock AgentCore
- AWS Lambda
- Amazon DynamoDB
- Amazon S3
- AWS Amplify

## Core Concept

The game is the interface.
The interaction is the measurement.
The agent orchestrates the longitudinal monitoring journey.

## Current Goal

Build a working autonomous AI agent that can:

1. Retrieve participant context
2. Retrieve longitudinal performance
3. Select an approved measurement task
4. Launch the task
5. Analyze gameplay
6. Store the result
7. Decide the next action

## Medical Disclaimer

NeuroQuest is a research prototype and is not a medical diagnostic tool.
